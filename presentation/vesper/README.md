# Vesper pitch deck

Open `index.html` in a browser (fullscreen it). Navigate with ← → / space / click; `Home`/`End` jump; `#N` in the URL opens slide N. Slide 7 autoplays `assets/isaac_fpv.mp4` (muted, looped; disabled under `prefers-reduced-motion`).

All imagery is ours, generated by the Vesper stack:

- `tac1.png`, `live_tactical.png`, `runs_page.png` — screenshots of the live web console (localhost:3000), Kramatorsk AO.
- `kill_frame.png`, `prog_0000/0040/final.png` — frames from native-sim tactical renders (`runs/20260905-144353-progression-test`).
- `isaac_kill.png`, `isaac_early.png`, `fpv_mid.png`, `isaac_fpv.mp4` — NVIDIA Isaac Sim RTX replay renders of recorded sorties (labeled in-deck as simulation renders, not combat footage).
- Slide 1 fiber-optic drone graphic and slide 2 GPS icon — original inline-SVG illustrations, labeled as illustrations in-deck.

Satellite basemap visible in console screenshots comes from the app's Kramatorsk map assets.
